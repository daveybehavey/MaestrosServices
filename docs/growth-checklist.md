# Immediate Growth Checklist

Use this as the quick-start checklist for the 30-day lead sprint.

## 1) Push the four priority offers everywhere

- Fence Refresh
- Rock Work Refresh
- Power Wash Reset
- Mulch Refresh

## 2) Use tracked links on every post

- GBP and Facebook links: see `docs/marketing-links.md`
- Keep `utm_source` and `utm_campaign` values consistent.

## 3) Run the weekly post cadence from a fixed calendar

- GBP: 3 posts/week
- Facebook: 5 local posts/week
- Monday: one "open slots this week" post (non-negotiable)
- Templates: see `docs/content-engine-templates.md`
- Calendar: see `docs/two-week-post-calendar.md`

## 4) Keep response speed tight

- Goal: first response within 1 hour during work hours.
- Use scripts and fallback ownership: see `docs/lead-response-playbook.md`

## 5) Ask for reviews and referrals after every completed job

- Send review request within 24 hours.
- Ask for one neighborhood introduction in the same follow-up.
- Templates: see `docs/review-request-template.md`

## 6) Track outcomes and channel quality weekly

- Update baseline and weekly results: `docs/weekly-scorecard.md`
- Run mobile funnel checks: `docs/funnel-qa-checklist.md`
- Keep channels with booked jobs, pause low-quality channels after 2 weeks.

## 7) Start LSA onboarding now

- Use `docs/lsa-onboarding-checklist.md`
- Track onboarding and launch status in `docs/weekly-scorecard.md`

## 8) Expand add-on service menu

- Gutter cleaning (ground-accessible)
- Light pruning
- Moss/algae treatment (surface-safe)
- Mention these as optional add-ons in quote follow-ups.
- Script/menu: `docs/add-on-services-menu.md`
