# Weekly Growth Routine

Use this every Monday morning. The goal is not perfection; the goal is consistent local visibility, fast follow-up, and more reviews.

Time needed: 30 to 45 minutes per week.

## Monday Setup

- [ ] Decide how many new jobs can be booked this week.
- [ ] Pick the top 2 services to push this week.
- [ ] Pick the top 3 areas to mention this week.
- [ ] Publish the Monday "open slots this week" GBP post.
- [ ] Publish the Monday Facebook/local post.
- [ ] Check all open leads from the last 7 days.

Use:

- `docs/two-week-post-calendar.md`
- `docs/gbp-post-calendar.md`
- `docs/lead-response-playbook.md`

## Daily Lead Rule

Every lead should get a fast first response.

- [ ] Reply within 1 hour during work hours.
- [ ] Ask for area, service, timing, and photos.
- [ ] If they go quiet, follow up once the next day.
- [ ] If they still go quiet, follow up once more 3 to 5 days later.

Short follow-up:

Hi [Name], just checking back in from Maestros Services. Did you still want help with [service]? If yes, send your area, timing, and a couple photos and I can help with the next step.

## Post-Job Review Rule

Every completed job gets a review request within 24 hours.

- [ ] Send the review link after the walkthrough or same day.
- [ ] Use `https://maestrosservices.com/review`.
- [ ] Ask for a referral if the customer seemed happy.
- [ ] Log whether the review was requested and received.

Use:

- `docs/review-request-template.md`

## Friday Check

- [ ] Follow up with every quote that has not booked.
- [ ] Publish one proof/process/weekend reminder post.
- [ ] Note which service generated the most replies.
- [ ] Repeat the strongest offer next Monday.
