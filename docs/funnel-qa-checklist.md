# Weekly Funnel QA Checklist (Mobile First)

Run this once per week.

## CTA and Contact Checks

- [ ] Header call button opens dialer.
- [ ] Hero call button opens dialer.
- [ ] Quote CTA scrolls or routes correctly to quote section/page.
- [ ] Sticky mobile CTA works.

## Quote Form Checks

- [ ] Form submits successfully from mobile.
- [ ] Success message shows on return (`submitted=1`).
- [ ] Error handling works (`error=1`).
- [ ] Required fields enforce correctly.

## Messaging Test Cadence (Sequential)

- Run one headline/CTA variant per week.
- Compare each variant against the previous week's winner.
- Keep winner based on qualified inquiries + booked jobs.

## Source Tracking QA

- [ ] Submit test lead from GBP tracked link.
- [ ] Submit test lead from Facebook tracked link.
- [ ] Confirm `utm_source` and `utm_campaign` show in lead email.

- [ ] Funnel healthy
