## Simple Posting Formula

Use this structure when creating new GBP posts:

1. Name the service or seasonal issue.
2. Explain the practical benefit in plain language.
3. Add one local or scheduling detail.
4. Ask for a photo, area, and timing.

Example:

We are booking [service] this week for homeowners in [area]. If you need help with [problem], send a photo, your location, and your ideal timing.
