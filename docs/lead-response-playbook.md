# Lead Response Playbook

Use this to keep response speed consistent.

## Response Standard

- Target: first response within 1 hour during work hours.
- Preferred first touch: call or text.
- If a call is missed, send a text-back within 10 minutes.

## First Response Script (Text)

Thanks for reaching out to Maestros Services. I can help with this.
What area are you in, what service do you need, and what timing are you aiming for?

## First Response Script (Form Lead)

Hi [Name], thanks for the quote request.
We can help with [Service if provided].
Can you confirm your area and ideal timing?
If easier, call or text us at 250-858-1781.

## Qualification Questions

- Area/neighborhood
- Service needed
- Timing window
- Access notes
- Budget range (optional)

## Fallback Ownership Rule

- Primary responder: Josh
- Backup responder: David
- If no reply in 45 minutes, backup responder takes over.
- If both are in jobsites, backup sends the first text and schedules callback window.

## Missed-Call Text Back Script

Thanks for calling Maestros Services. Sorry we missed you.
What area are you in, what service do you need, and what timing are you aiming for?
For fastest service, call or text 250-858-1781.

## Weekly Capacity Update Rule

Every Monday morning, confirm:
- how many new jobs can be booked this week
- which service slots are open
- which areas are already clustered

Then post an "open spots this week" update using tracked links.

## Post-Job Follow-Up Rule (Within 24 Hours)

- Send review request within 24 hours of completed work.
- Ask for one neighborhood referral within the same message thread.
- Log "review requested" and "referral requested" in the weekly scorecard notes.
